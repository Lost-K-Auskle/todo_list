# To-Do List Application

一个功能丰富的待办事项列表应用，基于 PyQt6 开发，支持多种主题、计时器、撤销重做等功能。

Tips:找不到想要的就只能自己整一个了o(╥﹏╥)o
## 功能特性

### 核心功能
- **任务管理**: 添加、删除、完成任务
- **双击操作**: 双击任务可快速标记完成
- **撤销/重做**: 支持操作撤销和重做，防止误操作
- **系统托盘**: 最小化到系统托盘，支持托盘菜单操作

### 计时功能
- **正向计时**: 记录任务执行时间
- **倒计时**: 设置专注时间，时间到自动提醒
- **实时时钟**: 可选在顶部显示当前时间

### 主题与外观
- **明亮模式**: 清爽的浅色主题
- **暗黑模式**: 护眼的深色主题
- **自定义背景**: 支持图片（PNG/JPG）、GIF动画、视频（MP4/AVI/MKV）作为背景
- **透明度调节**: 可调整窗口透明度（10%-100%）
- **实时预览**: 设置时实时预览效果

### 任务完成样式
- **样式1**: 完成后直接移除任务
- **样式2**: 完成后保留并划线显示
- **确认提示**: 可选择是否在删除/完成时显示确认对话框

## 环境要求

- Python 3.8+
- PyQt6
- PyQt6-Multimedia（可选，用于视频背景支持）

## 安装依赖

```bash
pip install PyQt6
pip install PyQt6-Multimedia  # 可选，用于视频背景
```

## 使用方法

### 启动应用

```bash
python todo_list.py
```

### 基本操作

1. **添加任务**: 在输入框中输入任务内容，按回车或点击"+"按钮
2. **完成任务**: 
   - 双击任务项
   - 或勾选任务前的复选框
3. **撤销操作**: 点击工具栏的"↩️"按钮
4. **重做操作**: 点击工具栏的"↪️"按钮
5. **打开设置**: 点击工具栏的"⚙️"按钮

### 计时器使用

1. 在设置中启用"启用计时器/倒计时"
2. 设置分钟数（0为正向计时，>0为倒计时）
3. 点击"▶"开始计时
4. 点击"⏸"暂停计时
5. 点击"↺"重置计时器

### 设置说明

#### 逻辑设置
- **任务样式**: 选择完成后的显示方式
- **删除/完成需确认**: 启用后操作前会弹出确认对话框

#### 功能扩展
- **显示当前时间**: 在窗口顶部显示实时时钟
- **启用计时器/倒计时**: 在任务列表下方显示计时器组件

#### 外观设置
- **主题风格**: 
  - 明亮模式
  - 暗黑模式
  - 自定义背景
- **不透明度**: 调整窗口透明度
- **背景文件**: 选择自定义背景（支持图片、GIF）

## 快捷键

- `Enter`: 添加任务
- `双击任务`: 切换完成状态


## 主要组件

- `TimerWidget`: 计时器组件，支持正向计时和倒计时
- `PreviewWidget`: 设置预览组件，实时预览主题效果
- `SettingsDialog`: 设置对话框，包含所有配置选项
- `TodoListApp`: 主应用程序类

## 注意事项

1. 自定义背景文件路径仅支持本地文件路径
2. 倒计时最大支持180分钟
3. 自定义背景文件路径会在下次启动时自动加载
4. 任务数据仅保存在内存中，关闭应用后会清空
